## 🎯 Features

-   **Authentication**: Role-based access (Admin/Cashier).
-   **Product Management**: Variants (Size/Color), Barcodes.
-   **Stock Management**: IN/OUT movements, Inventory tracking.
-   **Point of Sale (POS)**: Cart, Cash/Card payments.
-   **Cash Session**: Open/Close shifts, Cash reconciliation.
-   **Dashboard**: Real-time stats.

## 🚀 Quick Start

1.  **Install Dependencies**:
    ```bash
    flutter pub get
    ```

2.  **Configure Firebase**:
    ```bash
    flutterfire configure
    ```

3.  **Run**:
    ```bash
    flutter run -d windows
    ```

For detailed instructions, please see **[Getting Started](documentation/01_GETTING_STARTED.md)**.
